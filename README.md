# prism-imageproc

[![DOI](https://zenodo.org/badge/1254713531.svg)](https://zenodo.org/badge/latestdoi/1254713531)
[![PyPI](https://img.shields.io/pypi/v/prism-imageproc)](https://pypi.org/project/prism-imageproc/)

Image processing for instruments modeled with [SpectroForge](https://github.com/prism-spectra/SpectroForge).
`prism-imageproc` maps detector images onto the focal plane of the instrument and removes diffraction slit
curvature, using the curve-map bundles generated by SpectroForge. It can be used stand-alone and is also used
internally by SpectroForge. The core is written in Rust and distributed as a Python package.

## Installation

```bash
pip install prism-imageproc
```

Requires Python 3.12 or newer. Pre-built wheels are published to [PyPI](https://pypi.org/project/prism-imageproc/);
each wheel and source distribution is also attached to the matching
[GitHub release](https://github.com/prism-spectra/prism-imageproc/releases).

## Source

Releases of this package are built and published from the PrISM library workspace, not from this repository,
so this branch contains only this README. The earlier pure-Python implementation (up to `v0.0.4`) is kept on the
[`archive/master`](https://github.com/prism-spectra/prism-imageproc/tree/archive/master) branch.
